Each part of the bank has its own file in `shared/`. Every option has a comment explaining what it does. Restart the resource after changing any of them. Admins can see what each part is set to right now under **Settings** in the [admin dashboard](/nerve_banking/admin#the-dashboard).

| File | What it sets |
| --- | --- |
| `shared/config.lua` | Debug, currency symbol, accent colour, lock screen, profile pictures, logo, interaction mode |
| `shared/config_accounts.lua` | Savings, shared, business, society and government accounts |
| `shared/config_limits.lua` | Limits and fees for deposits, withdrawals, transfers and ATMs |
| `shared/config_cards.lua` | Debit cards, PINs, lockout, fees and the card item |
| `shared/config_atm.lua` | ATM screen mode, camera, session length, what ATMs allow |
| `shared/config_atms.lua` | ATM models and their screen positions, extra ATM locations |
| `shared/config_banks.lua` | Bank branches, blips and tellers |
| `shared/config_finance.lua` | Interest, tax, loans, credit score, overdraft and scheduled payments |
| `shared/config_admin.lua` | Admin dashboard, exports, fraud flags and Discord logs |

## Change these first [#change-these-first]

- **`society.jobs`** in `shared/config_accounts.lua` lists the jobs with a society account and the lowest grade that can view, deposit, withdraw and manage it. `police`, `ambulance` and `mechanic` are set up by default. Add your own jobs, or set `allJobs = true` to give every job one.
- **`government.accounts`** in the same file holds the city treasury and the job that runs it (`government` by default). Tax is paid into it.
- **`shared/config_banks.lua`** lists the branches: the eight GTA banks. If an MLO moves a counter, set `coords` to where the player stands at it. Turn on a `teller` for a clerk behind the counter.
- **`shared/config_limits.lua`** sets how much players can withdraw and transfer per transaction and per day, and any fees. ATMs have tighter limits of their own. Set `transferAnywhere = true` to allow transfers wherever the banking screen is open.
- **`shared/config_finance.lua`** holds interest, tax, loans, credit scores and overdrafts. Each is off until you set `enabled = true`. Scheduled payments are on by default.
- **`ui.accent`** in `shared/config.lua` is the highlight colour on the banking and ATM screens, as a hex code.
- **`ui.unlock`** decides the lock screen: `'pin'` (the player's debit card PIN, or a hold button for players without a card), `'hold'` (press and hold) or `false` (no lock screen). **`ui.unlockMinutes`** is how long the screen stays unlocked.
- **`interaction.mode`** is `'target'` (ox_target), `'textui'` (an ox_lib prompt and E) or `'3dtext'` (floating text and E).
- **`useItem`** in `shared/config_cards.lua` hands cards out as the `bank_card` item. Set it to `false` to keep cards in the bank. See [Installation](/nerve_banking/installation#step-3-add-the-card-item).
- **`transfer`** in `shared/config_atm.lua` is off by default, so transfers happen at a branch. See [ATMs](/nerve_banking/atms) for the rest.

## Profile pictures [#profile-pictures]

Players with Discord linked see their Discord profile picture in the bank. Everyone else keeps their initials. The picture is looked up by the player's Discord user id through the service set in `ui.avatars.api`, which must answer like Discord's user object. Set `ui.avatars.enabled = false` to keep initials for everyone and send nothing.

## Your logo [#your-logo]

To show your server's logo at the foot of the bank's side menu, put the image files (PNG or WebP) in the resource's `images` folder, or use https:// links, and set `ui.logo`:

```lua
logo = { mark = 'images/mark.png', wordmark = 'images/wordmark.png' },
```

The mark shows while the menu is closed. The wider wordmark is optional and shows while it is open.

## Money and accounts [#money-and-accounts]

- Players' checking balance is their framework bank money. Savings, shared, business, society and government accounts are held by the bank itself.
- Amounts are whole dollars. Rates are in basis points: 100 bp is 1%.
- Daily limits reset at 00:00 UTC. Interest, tax and overdraft fees run on fixed UTC cycles, so a restart never pays or charges the same cycle twice.
- Fees go to the bank's own fee account, not to a player or society.

### `shared/config.lua` [#config]

```lua title="shared/config.lua"
-- General settings. Each part of the bank has its own file next to this one:
--   config_accounts.lua  account types, shared, savings, business, society and government accounts
--   config_limits.lua    deposit, withdrawal and transfer limits and fees
--   config_cards.lua     debit cards and PINs
--   config_atm.lua       how ATMs look and behave
--   config_atms.lua      ATM models and extra ATM locations
--   config_banks.lua     bank branches (where the full banking screen opens)
--   config_finance.lua   interest, tax, loans, credit score, overdraft and scheduled payments
--   config_admin.lua     admin dashboard, fraud flags and Discord logs

return {
    debug = false,  -- Print troubleshooting detail to the console
    currency = '$', -- Symbol shown before amounts

    -- Look of the banking screens
    ui = {
        accent = '#a855f7', -- Highlight colour in the banking screens and on ATM screens (hex)
        locale = 'en-US',   -- Number and date format in the screens (any browser locale, e.g. 'de-DE')
        unlock = 'pin',     -- Lock screen when the banking screen opens: 'pin' (the player's debit card PIN; players without a card hold a button instead), 'hold' (press and hold to unlock) or false (no lock screen)
        unlockMinutes = 10, -- Minutes the banking screen stays unlocked before it asks for the PIN again
        avatars = {         -- Players' Discord profile pictures in the banking screen (players without Discord linked keep their initials)
            enabled = true,  -- false = always show initials
            api = 'https://discord-api-cfworker.chroniclesla.workers.dev/api/v1/user/', -- Lookup service the player's Discord id is appended to; it must answer like Discord's user object with avatar.link
        },
        logo = false,       -- Your server's logo at the bottom of the side menu, e.g. { mark = 'images/mark.png', wordmark = 'images/wordmark.png' }: a file in this resource's images folder or an https:// link; the mark shows while the menu is closed, the wider wordmark (optional) while it is open (false = no logo)
    },

    -- How players interact with banks and ATMs
    interaction = {
        mode = 'target',     -- 'target' (ox_target), 'textui' (ox_lib prompt and E), or '3dtext' (floating text and E)
        distance = 1.5,      -- Metres from a bank counter or ATM to interact
        key = 38,            -- Control for 'textui' and '3dtext' (38 = E)
    },

    accounts = lib.load('shared.config_accounts'), -- Account types: shared/config_accounts.lua
    limits = lib.load('shared.config_limits'),     -- Limits and fees: shared/config_limits.lua
    cards = lib.load('shared.config_cards'),       -- Debit cards: shared/config_cards.lua
    atm = lib.load('shared.config_atm'),           -- ATM behaviour: shared/config_atm.lua
    atms = lib.load('shared.config_atms'),         -- ATM models and locations: shared/config_atms.lua
    banks = lib.load('shared.config_banks'),       -- Bank branches: shared/config_banks.lua
    finance = lib.load('shared.config_finance'),   -- Interest, tax, loans, credit, overdraft, scheduled payments: shared/config_finance.lua
    admin = lib.load('shared.config_admin'),       -- Admin, fraud flags and Discord logs: shared/config_admin.lua
}
```

### `shared/config_accounts.lua` [#config-accounts]

```lua title="shared/config_accounts.lua"
-- Account types and who may use them. Read by `accounts` in shared/config.lua.
--
-- Job grades below are the framework grade numbers (0 is the lowest grade).
-- A grade of false means nobody gets that permission by grade alone; with
-- bossManages on, the job's boss grade still gets everything.

return {
    -- Personal checking. Every character gets one; its balance is your framework's
    -- own bank money, so other scripts that pay into or charge the bank keep working.
    checking = {
        label = 'Personal Checking', -- Name a new checking account gets (players can rename theirs)
    },

    -- Savings accounts players open themselves. They earn interest when interest is on in config_finance.lua
    savings = {
        enabled = true,             -- false: players can't open new savings accounts (open ones keep working)
        label = 'Savings',          -- Name a new savings account gets when the player leaves the name empty
        maxPerPlayer = 2,           -- Savings accounts one character can have open at once (0 = none)
        withdrawCooldownHours = 24, -- Hours a savings account must wait after a withdrawal or transfer out before the next one (0 = no wait)
        depositCooldownMinutes = 0, -- Minutes a savings account must wait after a deposit or transfer in before the next one (0 = no wait)
        maxBalance = 0,             -- Most a savings account can hold, in dollars; deposits that would go over it are refused (0 = no cap)
    },

    -- Shared accounts: one owner, other players added at the bank counter with their own permissions and limits
    shared = {
        enabled = true,             -- false: players can't open new shared accounts (open ones keep working)
        label = 'Shared Account',   -- Name a new shared account gets when the player leaves the name empty
        maxPerPlayer = 2,           -- Shared accounts one character can own at once (0 = none)
        maxHolders = 5,             -- People on one shared account besides its owner
    },

    -- Business accounts, created by other scripts through the CreateBusinessAccount export or from jobs below
    business = {
        enabled = true,              -- false: no new business accounts are created (existing ones keep working)
        fromJobs = false,            -- true: the boss of any job without a society account below gets a business account for it the first time they open the bank; or a list of job names, e.g. { 'burgershot', 'bennys' }
        maxEmployees = 25,           -- People on one business or society account besides its owner
        maxSalary = 0,               -- Highest salary per payroll run one employee can be given, in dollars (0 = no cap)
        payrollCooldownMinutes = 30, -- Minutes between two payroll runs a player starts on one business or society account (0 = no wait; scheduled payroll never waits)
    },

    -- Society accounts: one shared account per job, used through job grades
    society = {
        enabled = true,             -- false: no society accounts at all
        bossManages = true,         -- The framework's boss grade of a job gets every permission on its society account
        requireDuty = false,        -- Only players on duty in your framework get their job's society permissions
        allJobs = false,            -- true: every framework job gets a society account, using `default` for jobs not listed in `jobs`

        -- Grades for jobs not listed in `jobs` when allJobs is on
        default = {
            viewGrade = false,      -- Lowest grade that sees the balance and transactions
            depositGrade = 0,       -- Lowest grade that can deposit
            withdrawGrade = false,  -- Lowest grade that can withdraw and transfer out
            manageGrade = false,    -- Lowest grade that manages the account: rename, add people, set salaries, run payroll
        },

        -- One entry per job name. label is what players see as the account's owner.
        jobs = {
            police = { label = 'LSPD', viewGrade = 0, depositGrade = 0, withdrawGrade = 3, manageGrade = 4 },
            ambulance = { label = 'EMS', viewGrade = 0, depositGrade = 0, withdrawGrade = 3, manageGrade = 4 },
            mechanic = { label = 'Mechanics', viewGrade = 1, depositGrade = 0, withdrawGrade = 3, manageGrade = 4 },
        },
    },

    -- Government accounts. Tax is paid into the first one unless config_finance.lua names another.
    government = {
        -- id is fixed once in use (don't rename it). Players of `job` at minGrade or above see the account and can
        -- deposit; spendGrade and above can withdraw and transfer; manageGrade and above manage it.
        -- spendGrade or manageGrade false: only the job's boss grade can.
        accounts = {
            { id = 'treasury', label = 'City Treasury', job = 'government', minGrade = 0, spendGrade = 3, manageGrade = 4 },
        },
    },
}
```

### `shared/config_admin.lua` [#config-admin]

```lua title="shared/config_admin.lua"
-- Admin dashboard, fraud flags, Discord logs and the developer exports.
-- Read by `admin` in shared/config.lua.
--
-- Who counts as an admin is decided in shared/editable.lua (Editable.IsAdmin).

return {
    -- Admin dashboard
    enabled = true,          -- Admins can open the dashboard (false refuses every dashboard request)
    command = 'bankadmin',   -- Chat command that opens the dashboard for admins (false for no command)

    -- Exports other resources use to move money and read accounts
    api = {
        enabled = true,      -- Other resources can use the exports (false refuses every call)
        allowed = '*',       -- Resources allowed to call them: '*' for any, or a list such as { 'my_shops', 'my_jobs' }
        reads = 600,         -- Read calls (balances, accounts, history) per resource per 10 seconds
        writes = 120,        -- Money and account changes per resource per 10 seconds
    },

    -- Fraud flags. A flag never touches the player or their money: it adds an alert to the
    -- admin dashboard for a person to review. Windows are in seconds, amounts in whole dollars.
    fraud = {
        enabled = false,      -- Run the checks below (false turns every check off)
        notifyAdmins = true,  -- Online admins get a notification for each new alert
        autoFreeze = false,   -- Freeze the account on severity 3 alerts until an admin unfreezes it (leave false unless you are sure)

        -- Severity is 1 (worth a look), 2 (suspicious) or 3 (act now). Set enabled = false on a rule to turn only that one off.
        rules = {
            -- Several large withdrawals by one player in a short time
            largeWithdrawals = { enabled = true, severity = 2, amount = 50000, count = 3, window = 600 },   -- 3 withdrawals of $50,000 or more within 10 minutes
            -- Many transfers by one player in a short time
            rapidTransfers = { enabled = true, severity = 1, count = 10, window = 120 },                    -- 10 transfers within 2 minutes
            -- Money sent back and forth between the same two accounts
            pingPong = { enabled = true, severity = 2, count = 4, window = 600 },                           -- 4 transfers alternating between two accounts within 10 minutes
            -- Wrong PINs at ATMs by one player
            failedPin = { enabled = true, severity = 2, count = 5, window = 900 },                          -- 5 wrong PINs within 15 minutes, on any of their cards
            -- A lot of cash paid in by one player
            largeCashDeposits = { enabled = true, severity = 2, amount = 250000, window = 3600 },           -- $250,000 or more of cash deposited within an hour
            -- Many refused transactions by one player (over limits, not enough money, frozen accounts)
            failedTransactions = { enabled = true, severity = 1, count = 15, window = 300 },                -- 15 refused transactions within 5 minutes
            -- A business or society withdrawal far above that account's usual size
            businessWithdrawals = { enabled = true, severity = 3, multiplier = 5, minAmount = 25000, minSamples = 5, days = 30 }, -- over 5x the 30-day average, at least $25,000, once the account has 5 earlier withdrawals
            -- The same amount to the same place, again and again
            duplicates = { enabled = true, severity = 1, count = 3, window = 120 },                         -- 3 identical transactions within 2 minutes
        },
    },

    -- Discord logs. Webhook links never go in this file: add them to server.cfg with `set`
    -- (never `setr`, which sends them to every player):
    --   set nerve_banking:webhook "https://discord.com/api/webhooks/..."            every category
    --   set nerve_banking:webhook:transfers "https://discord.com/api/webhooks/..."  one category (overrides the one above)
    discord = {
        enabled = true,        -- Send logs to Discord when a webhook is set (false sends nothing)
        username = 'Bank',     -- Name the webhook posts as
        avatar = '',           -- Picture the webhook posts with (an https link, '' for the webhook's own)
        footer = '',           -- Small text under every log ('' for none)
        showIdentifiers = false, -- Add the player's character identifier to every log (false shows names only)
        queueLimit = 500,      -- Logs waiting to be sent before new ones are dropped (while Discord is down)

        -- One entry per kind of log. colour is a decimal colour (0xRRGGBB works too).
        categories = {
            deposits          = { enabled = true, colour = 0x34d399, title = 'Deposit' },               -- Cash paid into accounts
            withdrawals       = { enabled = true, colour = 0xfbbf24, title = 'Withdrawal' },            -- Cash taken out of accounts
            transfers         = { enabled = true, colour = 0xa855f7, title = 'Transfer' },              -- Money between accounts
            failed            = { enabled = true, colour = 0xef4444, title = 'Refused transaction' },   -- Transactions the bank refused
            business          = { enabled = true, colour = 0x60a5fa, title = 'Business account' },      -- Money in and out of business accounts, payroll
            society           = { enabled = true, colour = 0x38bdf8, title = 'Society account' },       -- Money in and out of job society accounts
            loans             = { enabled = true, colour = 0xc084fc, title = 'Loan' },                  -- Loan payouts and decisions
            loan_repayments   = { enabled = true, colour = 0x34d399, title = 'Loan repayment' },        -- Loan installments and repayments
            interest          = { enabled = false, colour = 0x34d399, title = 'Interest' },             -- Savings interest payouts (one per account per cycle, can be many)
            tax               = { enabled = false, colour = 0xfbbf24, title = 'Tax' },                  -- Wealth tax collected (one per account per cycle, can be many)
            overdraft         = { enabled = true, colour = 0xfbbf24, title = 'Overdraft fee' },         -- Overdraft interest and fees
            cards             = { enabled = true, colour = 0xa855f7, title = 'Card' },                  -- Cards issued, locked, replaced, cancelled; card fees
            accounts          = { enabled = true, colour = 0xa855f7, title = 'Account' },               -- Accounts opened, renamed, closed
            freezes           = { enabled = true, colour = 0xef4444, title = 'Account frozen' },        -- Accounts frozen and unfrozen
            fraud             = { enabled = true, colour = 0xef4444, title = 'Fraud alert' },           -- Fraud flags
            admin             = { enabled = true, colour = 0xededed, title = 'Admin action' },          -- Adjustments, reversals and other admin actions
            permissions       = { enabled = true, colour = 0x60a5fa, title = 'Account access' },        -- People added to or removed from accounts, permission changes
            scheduled_failures = { enabled = true, colour = 0xef4444, title = 'Scheduled payment failed' }, -- Scheduled payments that could not run
        },
    },
}
```

### `shared/config_atm.lua` [#config-atm]

```lua title="shared/config_atm.lua"
-- How ATMs look and behave. Read by `atm` in shared/config.lua.
--
-- An ATM shows the bank on its own screen: the player walks up, the camera moves
-- in front of the screen and they use it with the mouse and the number keys.
-- Models without a screen in shared/config_atms.lua, and players whose game
-- cannot show the screen, get the same ATM as a screen overlay instead.

return {
    enabled = true,              -- Players can use ATMs at all (false = no ATM interactions anywhere)

    -- Where the ATM screen is drawn:
    --   'auto'  on the ATM's own screen when the model has one in config_atms.lua, otherwise (or when
    --           that screen does not start within 5 seconds) as an overlay
    --   'dui'   always on the ATM's own screen; shows an error instead of the overlay when it fails
    --           (useful while calibrating screens)
    --   'nui'   always as an overlay
    --   'off'   ATMs do nothing (same as enabled = false)
    mode = 'auto',

    -- How the page gets onto an ATM's own screen:
    --   'auto'     in place of the machine's own screen picture where the model has one (it fits the
    --              glass exactly), otherwise drawn over the glass. While a player uses an ATM, every
    --              ATM of the same model near them shows their screen too, on their game only.
    --   'quad'     always drawn over the glass, so only the machine in use shows it
    screenMethod = 'auto',

    duiWidth = 1024,             -- Pixel width of the screen page; its height follows the shape of each model's screen
    duiIdleSeconds = 120,        -- Seconds the screen page stays loaded after the last use, so the next ATM opens instantly (0 = unload straight away)

    sessionSeconds = 60,         -- Seconds without input before the ATM ends the session and ejects the card (at least 15)
    leaveDistance = 2.5,         -- Metres a player can move from the ATM before the session ends

    -- What players can do at an ATM. Withdrawals and balance checks are always available.
    deposit = true,              -- Deposit cash into an account
    transfer = false,            -- Transfer to another account number (false = only at a bank branch)
    pinChange = true,            -- Change a card's PIN

    quick = { 20, 50, 100, 200, 500, 1000 }, -- Quick-pick amounts on the withdrawal screen, in whole dollars (up to 8)
    maxWithdraw = 0,             -- Most an ATM pays out in one withdrawal, in dollars, on top of the limits in config_limits.lua (0 = no ATM cap)
    statementRows = 8,           -- Recent transactions shown on the ATM's mini statement

    -- Presentation
    camera = true,               -- Move the camera in front of the screen (false = keep the player's own view)
    cameraEase = 500,            -- Milliseconds the camera takes to move in and out (0 = cut straight to it)
    cameraFov = 40.0,            -- Field of view of that camera in degrees, unless a model sets its own in config_atms.lua
    cameraFill = 0.7,            -- How much of the view the screen fills when a model's camera has no fixed position (0.2 to 1.0)
    cameraLift = 10.0,           -- Degrees the camera looks down onto the screen from straight in front of it
    hideHud = true,              -- Hide the HUD and minimap while the screen is in use
    sounds = true,               -- Play the game's keypad sound when a key is pressed on the screen

    -- Animation while the player stands at the ATM (false = no animation)
    animation = {
        dict = 'amb@prop_human_atm@male@idle_a', -- Animation dictionary
        clip = 'idle_b',                         -- Animation inside the dictionary
    },

    -- Map blips for the ATMs in shared/config_atms.lua `locations` and the ones admins
    -- register in game. The ATMs already in the GTA world have no blip.
    blips = {
        enabled = false,         -- Show these blips (true or false)
        sprite = 277,            -- Blip icon (277 = dollar sign)
        colour = 2,              -- Blip colour (2 = green)
        scale = 0.7,             -- Blip size
    },

    -- Chat command that lines up the nearest ATM's screen and camera in game. Only
    -- admins can use it (nerve_banking.admin, or the framework's admin groups; see
    -- Editable.IsAdmin). What they save applies to that model for every player.
    -- false = no command.
    calibrate = 'atmcalibrate',
}
```

```lua title="shared/config_atms.lua"
-- ATM models and extra ATM locations. Read by `atms` in shared/config.lua.
--
-- models: every prop players can use as an ATM, wherever it stands in the world.
--   model     the prop's model name
--   label     name shown on the ATM's screen (leave out for the default "ATM")
--   settings  this model's own choices, overriding shared/config_atm.lua:
--             { deposit = true/false, transfer = true/false, pinChange = true/false,
--               maxWithdraw = dollars, fee = { flat = dollars, bp = basis points, max = dollars } }
--   screen    where the glass is, in metres from the prop, seen by a player standing in
--             front of it: x = right, y = into the machine, z = up. Either
--               { center = vec3(...), width = m, height = m, tilt = degrees the top leans back }
--             or the four corners
--               { topLeft = vec3(...), topRight = vec3(...), bottomLeft = vec3(...), bottomRight = vec3(...) }

--             the camera stands, as an offset from the prop. It always looks at the screen.
```

### `shared/config_banks.lua` [#config-banks]

```lua title="shared/config_banks.lua"
-- Bank branches. Read by `banks` in shared/config.lua.
--
-- Each branch is a counter where the full banking screen opens. ATMs are set
-- up separately in shared/config_atms.lua.
--
-- One entry per branch:
```

### `shared/config_cards.lua` [#config-cards]

```lua title="shared/config_cards.lua"
-- Debit cards and PINs. Read by `cards` in shared/config.lua.
--
-- A card belongs to one player and draws on one account. Players order cards
-- at a bank and use them at ATMs with their PIN. Only the last four digits of a
-- card number are ever shown, and PINs are stored as one-way hashes, so nobody
-- (staff included) can read a player's PIN back.

return {
    enabled = true,          -- Players can order debit cards (false = no cards, and ATMs stay closed because they need one)

    -- Physical card item. With it on, players get a card in their inventory
    -- when it is ordered, and ATMs only offer the cards a player carries.
    -- Add the item first: install/ox_inventory/ has the items.lua entry and
    -- the picture. Until the item exists, cards stay bank-only and the console
    -- says so once.
    useItem = true,          -- Hand out cards as an inventory item (false = cards live only in the bank; every ATM offers all of a player's cards)
    item = 'bank_card',      -- Name of the card item in your inventory

    -- PINs
    pinLength = 4,           -- Digits in a PIN (4 to 8)
    maxAttempts = 3,         -- Wrong PINs in a row before the card is blocked (1 or more)
    lockMinutes = 30,        -- Minutes a card stays blocked after too many wrong PINs
    activation = false,      -- true: new cards arrive inactive and the player picks the PIN later under Change PIN (false = the PIN is chosen when ordering)

    -- Ordering
    expiryYears = 4,         -- Years until a new card expires; an expired card can be replaced for the replacement fee
    issueFee = 50,           -- Dollars charged to the account when a card is ordered (0 = free)
    replaceFee = 100,        -- Dollars charged to the account when a card is replaced (0 = free)
    maxPerAccount = 1,       -- Cards one player can hold on the same account at once (1 or more)
    issuePerm = 'withdraw',  -- What another player needs on a shared, business or society account to order a card for it: 'withdraw', 'transfer' or 'manage' (account owners can always order)
    accountTypes = { 'checking', 'savings', 'shared', 'business', 'society' }, -- Account types a card can draw on

    -- Spending limits a new card starts with. Players can lower or raise them on
    -- the card later. The account's own limits always apply on top.
    limits = {
        perTx = 0,           -- Most dollars in one ATM transaction with the card (0 = only the account's limits)
        daily = 0,           -- Most dollars per day with the card (0 = only the account's limits)
    },
}
```
