## Notifications

Every notification the script shows goes through one function, `Editable.Notify`, in `shared/editable.lua`. It uses ox_lib notifications by default, so most servers don't need to change anything.

```lua title="shared/editable.lua"
function Editable.Notify(message, kind)
    lib.notify({ title = locale('title'), description = message, type = kind })
end
```

| Argument | What it is |
| --- | --- |
| `message` | The text to show, already translated |
| `kind` | `'success'`, `'error'` or `'inform'` |

### Use another notification system

The file has ready examples below the ox_lib line for lation_ui, okokNotify, brutal_notify, wasabi_notify, t-notify, mythic_notify, pNotify, qbx_core, ESX and the GTA feed above the minimap.

1. Open `shared/editable.lua`.
2. Delete the `lib.notify(...)` line.
3. Remove the `--` in front of the example for your system.
4. Restart the resource.

For example, to use okokNotify:

```lua
function Editable.Notify(message, kind)
    exports.okokNotify:Alert(locale('title'), message, 5000, kind == 'inform' and 'info' or kind)
end
```

### Use your own code

Replace the body with any call your server uses. Map `kind` to whatever your system expects:

```lua
function Editable.Notify(message, kind)
    exports['my_notify']:Send(message, kind)
end
```

<Callout type="info">

If your notification code throws an error, the message is shown in the GTA feed instead, so players never miss it. `shared/editable.lua` is kept readable in your download, so you can change it at any time.

</Callout>

## Languages

The script uses ox_lib's language setting. Nine languages are included: English (`en`), German (`de`), Spanish (`es`), French (`fr`), Italian (`it`), Dutch (`nl`), Polish (`pl`), Portuguese (`pt`) and Turkish (`tr`).

Set the language in `server.cfg`:

```cfg
setr ox:locale de
```

This changes the menu and every notification. It is the same setting your other ox_lib resources use.

### Changing the text

All text lives in the `locales/` folder, one file per language. To change a word or sentence, edit the value in your language's file and restart the resource. Keep every `%s` in place. It is replaced with a name, number or command, for example:

```json
"invite_sent": "Invite sent to %s."
```

### Adding a language

1. Copy `locales/en.json` to a new file named after the language code, for example `locales/sv.json`.
2. Translate the values. Leave the keys on the left as they are.
3. Set `setr ox:locale sv` in `server.cfg` and restart the server.
